# Shadab Alam — Portfolio

> A fluid, modern editorial digital experience showcasing interactive web applications, 3D browser games, utilities, and interface experiments.

## 🚀 Featured Projects

1. **Chess Online 3D** — Interactive browser-based 3D chess game built with Three.js & spatial logic.
   - [Repository](https://github.com/sh4dabexe/ChessOnline3D) • [Live Demo](https://chess-online3-d.vercel.app/)
2. **Cutter** — Fast, client-side image cropping and resizing browser utility.
   - [Repository](https://github.com/sh4dabexe/Cutter) • [Live Demo](https://cutter-black.vercel.app/)
3. **TypeForge** — Modern typing engine focused on real-time feedback and telemetry tracking.
   - [Repository](https://github.com/sh4dabexe/Typeforge)
4. **Ludo Online** — Online multiplayer board game recreating classic mechanics for the web.
   - [Repository](https://github.com/sh4dabexe/LudoOnline) • [Live Demo](https://ludo-online-phi.vercel.app/)
5. **Birthday Present** — Interactive celebratory web surprise with custom animations.
   - [Repository](https://github.com/sh4dabexe/BirthdayPresent)
6. **Flappy Bird Clone** — Recreation of classic arcade physics and game loops using Python / Pygame.
   - [Repository](https://github.com/sh4dabexe/Flappy-Bird)

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Engine**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + Custom CSS Design System
- **Animation**: [Framer Motion](https://www.framer.com/motion/) + SVG Path Interpolation
- **Icons**: [Lucide React](https://lucide.dev/) + Custom Brand SVGs

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
